# ddos.py

A dependency-free UDP and HTTP flood tool for **Termux** (Android) and **iSH** (iOS).
One Python file, no third-party packages. It's a toy flooder for knocking over small
targets — not a real load tester.

## Installation

```bash
git clone https://github.com/itzzEIias/ddos.py.git
cd ddos.py
chmod +x ddos.py
